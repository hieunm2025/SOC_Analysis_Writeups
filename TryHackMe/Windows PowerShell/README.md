# Powershell
From the microsoft page:" Powershell is a cross-platform task automotion solution made up of a command-line shell, a script language, and a configuration management framework"

It designed for task automation and configuration managemnet. It combines a command line interface and a scripting language built on the .NET framework. 
Powershell is object-oriented, which means it can handle complex data types and interact with system components more effectively.

History:
 Powershell was developed to overcome limitations of existing command-line tools and scripting environments in Windows. Micosoft need a tool that could handle more sophisticated administrative tasks and interact with Window's modern APIs.

 Windows used structured data and APIs, while Unix treated everything as text files.
